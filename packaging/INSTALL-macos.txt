Datamosh for Resolume — macOS
=============================

Use the installer
-----------------

Download datamosh-<version>-macos.pkg from the releases page, double-click it,
and follow the prompts. It is signed and notarised by Apple, so there is no
security warning and nothing to type into a Terminal.

It installs into your own Documents folder, so no administrator password is
needed. Tick Arena, Avenue or both.

Quit Resolume first — it scans for plugins only when it starts.


This zip, if you would rather copy files by hand
------------------------------------------------

1. Copy both bundles into Resolume's plugin folder:

       ~/Documents/Resolume Arena/Extra Effects/

   (Resolume Avenue users: ~/Documents/Resolume Avenue/Extra Effects/)

   Datamosh.bundle             the effect
   DatamoshTransplant.bundle   the mixer, appears as a blend mode

2. Clear the quarantine flag.

   macOS attaches a quarantine attribute to anything extracted from a
   downloaded zip, and will then refuse to let Resolume load the plugins.
   There is no error message: they simply do not appear, which looks
   identical to a failed install.

   In Terminal:

       xattr -dr com.apple.quarantine ~/Documents/Resolume\ Arena/Extra\ Effects/Datamosh.bundle
       xattr -dr com.apple.quarantine ~/Documents/Resolume\ Arena/Extra\ Effects/DatamoshTransplant.bundle

   The installer exists precisely to avoid this step — package payloads are
   not quarantined. Building from source also avoids it.

3. Restart Resolume.

   Datamosh appears in the Effects list. Drop it on a layer, a group, or the
   composition — the composition is where it is at its most useful, with Auto
   Mode set to On Cut.

   Mosh Transplant appears in a layer's blend-mode dropdown, not the
   effects list. It applies that layer's motion to the layers below it.


Which version do I have?
------------------------

Right-click Datamosh.bundle in Finder, choose Get Info, and read Version.
Both bundles carry it. Inside Resolume the version is also on the end of the
effect's description, and on the "datamosh:" line the plugin writes to
Resolume's log the first time it allocates buffers.

The plugin's own NAME never carries the version, deliberately. Resolume
addresses an effect by its name, so a name that changed every release would be
a saved composition that quietly failed to find its effect after an upgrade.

Requirements
------------

Resolume 7.3 or later. 7.11+ for Apple Silicon, which these bundles support
natively — they are universal binaries carrying both arm64 and x86_64.

Resolume 7.4 or later shows the Licence field's status ("Licence: active",
"locked", the crash-report question) in the panel. On 7.3 the field still
works, but its name stays "Licence"; the status is in README.txt in the
licence folder and in Resolume's log.

Parameter groups need 7.3+; on older versions the parameters still work but
appear as one flat list.


Licence
-------

Datamosh needs a licence key or a free trial. Without one, a new Datamosh
passes video through untouched, and the last parameter's name reads
"Licence: locked, ...".

Click that Licence field, type your licence key (LT-DATA-...) or, for a
trial, your email address, and press Enter. The field empties and its name
changes to "Licence: active" or "Licence: trial, N days left" within a few
seconds; effects already in the composition unlock straight away. An effect
that is already running is never locked, online or off.

Type "folder" to open the licence folder:

    ~/Library/Application Support/LeTissier/Datamosh/

Its README.txt has the status, and the request code for activating a
computer that is offline.


Feedback and crash reports
--------------------------

The Send Feedback button (in the Help section, just above Licence) opens the
feedback page in your browser. Typing "feedback" into the Licence field does
the same.

Crash reports are off unless you turn them on. If Resolume closes while
Datamosh is working on a frame, the next time it starts the Licence field asks
once: type "send" to send a report, or "discard". Type "always send" to send
reports without being asked, and "reports off" to stop. A report never
contains your licence key, email address, name or anything from your
composition; README.txt in the licence folder shows exactly what it holds.

Status
------

Version 1.0.0 is the first release sold with a licence. Everything in it is
verified by an automated test suite against synthetic footage, and it loads
and runs in Resolume -- the smoke test passes on a real host. The full pass
(aesthetic sweeps, a long soak, the mixer in depth) has not been done, and the
tuning defaults have never been judged against real footage. Rehearse with it
before you put it in a show.
