Datamosh for Resolume — macOS
=============================

1. Copy both bundles into Resolume's plugin folder:

       ~/Documents/Resolume Arena/Extra Effects/

   (Resolume Avenue users: ~/Documents/Resolume Avenue/Extra Effects/)

   Datamosh.bundle             the effect
   DatamoshTransplant.bundle   the mixer, appears as a blend mode

2. IMPORTANT — clear the quarantine flag.

   These bundles are not code-signed or notarised. macOS attaches a quarantine
   attribute to anything downloaded from a browser, and Gatekeeper will then
   stop Resolume loading them. There is no error message: the plugins simply do
   not appear in the effects list, which looks identical to a failed install.

   In Terminal:

       xattr -dr com.apple.quarantine ~/Documents/Resolume\ Arena/Extra\ Effects/Datamosh.bundle
       xattr -dr com.apple.quarantine ~/Documents/Resolume\ Arena/Extra\ Effects/DatamoshTransplant.bundle

   Building from source instead avoids this entirely, since a locally built
   bundle is never quarantined.

3. Restart Resolume.

   Datamosh appears in the Effects list. Drop it on a layer, a group, or the
   composition — the composition is where it is at its most useful, with Auto
   Mode set to On Cut.

   Datamosh Transplant appears in a layer's blend-mode dropdown, not the
   effects list. It applies that layer's motion to the layers below it.


Requirements
------------

Resolume 7.3 or later. 7.11+ for Apple Silicon, which these bundles support
natively — they are universal binaries carrying both arm64 and x86_64.

Parameter groups need 7.3+; on older versions the parameters still work but
appear as one flat list.


Documentation
-------------

https://datamosh.letissier.ie


Status
------

This is a pre-release. Everything in it is verified by an automated test suite
against synthetic footage, but it has not yet been run inside Resolume itself,
and the tuning defaults have never seen real video. Treat it as something to
try, not something to put in a show without rehearsing it first.
